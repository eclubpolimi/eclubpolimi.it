# E-Club Polimi Website

Official website of the **Entrepreneurship Club at Politecnico di Milano (E-Club Polimi)** — mission, events, team, network, and applications.

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **Astro 5.x** | Framework, server output on Vercel |
| **React 19** | Interactive islands (`client:load` / `client:only`) |
| **TypeScript** | Type-safe development |
| **Tailwind CSS 4.x** | Utility-first styling (CSS-first config, no `tailwind.config.js`) |
| **shadcn/ui + Radix** | `dialog` primitive (gallery lightbox) |
| **Contentful** | CMS: team, events, images, copy |
| **Vercel** | Deployment & edge runtime |

## Getting Started

Prerequisites: Node.js 18+, npm.

```bash
git clone <repo-url>
cd eclubpolimi.it
npm install
```

Create `.env` with Contentful credentials (see `.env` — never commit it):

```env
CONTENTFUL_SPACE_ID=your_space_id
CONTENTFUL_ENVIRONMENT=master
CONTENTFUL_DELIVERY_TOKEN=your_delivery_token
CONTENTFUL_PREVIEW_TOKEN=your_preview_token
```

```bash
npm run dev      # dev server on :3000
npm run build    # production build
npm run preview  # preview production build
npx astro check  # type check
```

## Design System

Single source of truth: `src/styles/global.css` (`@theme`).

| Token | Value | Usage |
|-------|-------|-------|
| `brand` | `#FC3F1A` | Primary CTA / accents |
| `brand-deep` | `#D93812` | CTA hover |
| `brand-soft` / `brand-ink` | `#FDE9E2` / `#9A2A0E` | Tinted chip bg + contrast-safe text |
| `brand-navy` / `brand-navy-deep` / `brand-navy-flat` | `#2B5DAA` / `#1E3A5F` / `#224371` | Navy surfaces & gradients |
| `accent-iris` / soft | `#514FC4` / `#EBEAFE` | Network card accent |

Utilities auto-generated by Tailwind v4: `bg-brand`, `text-brand-ink`, `border-brand`, …

Shared helpers: `.section-pad`, `.container-site`, `.img-zoom`, `.expandable`,
`.animate-fade-up{,-1,-2,-3}`, `.animate-bounce-slow`, global `:focus-visible` ring,
`prefers-reduced-motion` kill-switch.

### ⚠️ Cascade-layer gotcha (read before styling `<a>` tags)

Webflow's `src/site-components/global.css` contains **unlayered** rules like
`a { background-color: transparent }`. Tailwind v4 puts utilities in cascade
layers — **unlayered author CSS always beats layered CSS**, so `class="bg-*"`
on an `<a>` is silently wiped. Fix: `src/styles/global.css` carries unlayered
`a.bg-…` / `button.bg-…` overrides next to the tokens. **When adding a new
background color to an anchor, add its override there too.**

Other conventions:

- Light mode only — `main.astro` strips `.dark`; do not add `dark:` variants.
- Fonts: Montserrat (headings, curated `<link>` in `main.astro`) + Arial/system body.
  Never re-import `generated/fonts.css` (~20-family mega-import).
- Icons: Lucide-style 24px stroke (`strokeWidth 1.8`, `currentColor`).
